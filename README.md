# DiphroME

A personal portfolio site built with Next.js, React, TypeScript and Tailwind CSS.

## Sections

Hero, about, projects, experiments, open source, skills, philosophy, writing and contact. Site content lives in `data/site`, and each section is a component in `components/`.

## Requirements

- Node.js 20 or newer
- npm or pnpm

## Run

    npm install
    npm run dev

Then open http://localhost:3000.

## Scripts

- `npm run dev` starts the development server
- `npm run build` creates a production build
- `npm run start` serves the production build
- `npm run lint` runs ESLint
